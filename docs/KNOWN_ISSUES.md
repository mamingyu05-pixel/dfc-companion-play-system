# 已知问题

更新于 2026-10-22。只记录仍然成立的问题；本地验证指在隔离 PostgreSQL 上跑完整 API 测试（203 项）与前端测试，不等于生产验证。

## 未经真实环境验证
1. Discord / KOOK 的派单、接单、回写只在测试里用模拟请求验证过，仍需用真实平台 Token 做端到端验证，包括双平台同时点击接单。
2. KOOK 加密包体已支持（需配置 `KOOK_ENCRYPT_KEY`）；压缩包体仍建议在 KOOK 后台设置 `compress=0`。
3. HTTPS（`scripts/enable-https.sh`、`apply-https-nginx.sh`）、备份（`backup-postgres.sh`）和上线冒烟（`smoke-production.sh`）脚本已提供，未在目标服务器上执行验证；监控与滚动发布尚未配置。
4. 微信小程序只接通登录，订单与支付未接通；自动支付、自动提现不在当前范围。

## 已知限制
5. 客户与陪玩的「我的订单」只返回最近 200 单；充值审核列表返回全部待审核（最多 500 笔）和最近 200 笔已处理记录。
6. 充值截图与订单凭证以 data URL 存在数据库中（每张最大 2MiB），列表只返回「是否有图」，图片按需单独读取。数据量大后应迁移到对象存储。
7. 保底护航的仓库价值由双方填写并附截图，系统只校验格式和净增门槛，数值真实性依赖客户验收与客服复核。
8. 小时陪玩价格不区分手游 / 端游；保底护航档位区分。
