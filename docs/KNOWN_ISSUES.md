## 尚未完成的验收

1. Discord、KOOK 真实频道的派单、通知回写、同时点击接单，以及微信真实 AppID、真机登录，尚未在本轮验收。数据库并发测试和模拟平台 HTTP 请求不能替代真实平台验收。
2. 原生小程序源码作为已有资产保留；其默认内存模式、隔离 TEST API 和微信登录原型不代表小程序商业闭环可用。第一阶段继续以三端网页为准，不新增小程序、APP、多游戏、自动付款或自动提现。
3. 公网域名、HTTPS、目标服务器备份恢复、Docker 镜像与云端 CI 尚未在本轮执行。现有 Windows 本机服务与本轮维护候选分开；本轮不部署。
4. 登录并发专项 R01 尚未收口：相关执行此前被自动安全审核以可能涉及网络安全风险拒绝。本轮没有重试、改写或绕过该项。现有认证测试的通过不能替代这个专项的验收。本轮浏览器脚本在登录尚未稳定时强制跳页，观察到会话校验被中断并清除本地会话；失败诊断已保留。正常等待登录完成后的业务检查单独统计，快速跳页情形不能记为已修复，也未据此改动认证源码。
5. 本轮已在独立的本机无界面 Edge 中验证人工调账 helper 的原生 Web Locks、真实 localStorage、双标签排队和结果不明后刷新恢复。该协议测试使用合成 HTTP 回执，不是银行/平台资金；其他浏览器、移动设备和人工验收尚未验证。后端 PostgreSQL 幂等与死锁保护有独立真实数据库回归。

## 当前产品与工程限制

- 客户和陪玩的未结束订单会单独查询，不再被最近 200 条历史记录挤掉；已结束历史保留最近 200 条窗口。后台订单列表最多返回 200 条匹配，完整历史应通过搜索/后续分页处理。
- 充值待审核列表最多 500 笔，已处理历史最近 200 笔。大量待办需后续分页优化。
- 后台用户页仍一次加载完整用户列表。6000多个合成用户时，自动化的全页角色/文字遍历和networkidle等待曾超时。本轮没有做用户页分页或大数据交互性能验收，正常页面/API与资金回执证据不能替代性能验收。
- 充值截图、订单凭证 data URL 存储在数据库中，每张最大 2 MiB，列表按需取图。增长后应评估对象存储、备份体积和保留策略。
- 保底护航仓库价值由双方填写并附图，格式和净增门槛可以自动校验，真实性依赖客户验收和人工复核。
- 小时陪玩价格不区分手游/端游，保底护航档位区分。
- 既有 Schema 和后台界面仍有其他游戏枚举/选项；本轮商业闭环只验三角洲，没有删除旧字段、旧数据，也不据此认定其他游戏可用。
- 依赖补丁审计在上一版记录中为高危/严重 0、中危 13、低危 5；本轮未重新安装或变更依赖。中低危仍保留，不能称所有依赖风险为零。
- 当前两个 Git 仓库为浅克隆。密钥扫描覆盖本机可用历史，不覆盖未下载历史、外部文件、数据库或远程服务中的凭据。
