# DFC 原生小程序

继续使用本目录作为现有小程序代码目录。微信开发者工具导入时选择包含本文件和 project.config.json 的文件夹，AppID 保持 wxe2812f4a7cbb2c64。未确认当前 IDE 已导入；没有进行开发者工具、真机、登录、支付或发布验收。

页面提供“选服务 → 核对金额 → 看订单／钱包”和验收与售后说明。默认 api-config.js 为 simulation、地址为空；模拟订单和余额仅驻内存，重开重置，不调用网络、微信登录或支付。

api-client.js 复用原后台报价、下单和本人回执接口，支持显式配置的本机隔离 API 模式。只有实际隔离数据库、服务端 TEST 标记和测试身份都核验后才可使用。测试会话由批准的接入步骤放入 getApp().globalData.testApiSession，仅驻内存；不要在文件或本地存储中填写令牌、密码或 AppSecret。默认不创建身份、不执行登录。

隔离模式先取服务端报价，再由用户确认精确金额；超时或结果未知时保留原请求编号，通过“刷新核对”查原回执，禁止重复提交。明确未提交的业务错误才允许重新报价。请求编号可以持久保存用于恢复，会话令牌不持久化。localhost 仅指本机，不能据此连接手机真机。

验收与投诉继续使用客户网页端；退款由客服与管理员人工裁决。已新增显式 `wechat-api` 模式的微信客户登录源码：用户点击登录后调用 wx.login，将 code 交后端校验，再用客户 JWT 核验 /auth/me。该模式只开放登录，订单与支付明确显示未接通；没有调用 wx.requestPayment。原生评价、投诉／退款提交和真机连接尚未验收。

真实模式与默认模拟、本机 TEST 严格分开，不接受本机 TEST 地址、身份或配置。会话只驻内存，退出或过期清除；不自动合并已有网页账户。服务端默认关闭，未写入任何真实凭据或执行登录。配置契约、迁移依赖、合成回归和平台待验收项见 [微信登录说明](../../docs/wechat-login.md)。

上级 miniapp-browser.html 是独立 H5 演示入口，不能代替微信原生验收。原 H5 文件和已有视频未在本次修改。

离线检查：node ui-logic.test.cjs 验证原生页面逻辑；node verify.cjs 验证原模型及静态结构。二者都不启动服务，不能证明真实平台链路已接通。接口与隔离条件见 integration-contract.json。


新增短时 TEST 连接直接使用本页，不另造演示页面。默认仍是模拟模式；只有用户输入本次控制台给出的精确 127.0.0.1 API 地址并申请，才切换到清楚标识的隔离模式。页面显示六位配对码，由操作者在本次受限 API 控制台输入 APPROVE 加配对码，再点击“核对本机授权”；这是临时本机测试身份，不是微信登录。缺少批准、服务未就绪或到期均不能下单，不会回退为假 API 成功。

会话/JWT只在内存，页面退出或断开会清除自有会话；未决订单请求编号继续保留，不能用重新申请代替结果核对。控制台 STOP 或资源/时间门槛关闭本次服务。api-config.js、project.config.json 和平台安全设置均不由该流程修改，手机真机不能借用电脑回环地址。

此次新增交互模式通过纯内存检查，但尚未通过真实微信编译、wx.request、控制台操作或人工下单验收。此前四组真实 HTTP→PG结果属于自动测试封装，不能充当新交互模式或微信平台验收。真实打开/权限步骤及本机窗口说明见 ../../scripts/isolated-test-api/README.md。
